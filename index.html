🧠A* Algorithm Explained

A* (A-Star) finds the optimal (shortest + safest) route from start to destination.

Route Cost Formula: f(n) = g(n) + h(n)
  • g(n) = actual cost from start to n
    (distance + danger penalties)
  • h(n) = estimated cost from n to goal
    (heuristic – straight-line distance)
  • Danger Penalty = danger_score × disaster_multiplier

Blocked roads get infinite cost and are completely excluded. The algorithm always prefers lower total cost routes.
